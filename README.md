# e-Absen SLB AN — PWA FINAL

PWA ini langsung membuka Web App Google Apps Script yang sudah diuji berhasil.

- Tidak meminta URL server kepada pengguna.
- Tidak memiliki toolbar tambahan.
- Shell PWA memenuhi tinggi layar perangkat.
- Kamera, geolocation, dan fullscreen diberikan ke iframe.
- Backend Apps Script tetap menjadi sumber transaksi login dan absensi.
- Service worker hanya meng-cache shell PWA, bukan backend Apps Script.

Deploy:
1. Upload/replace file-file ini di repository GitHub Pages.
2. Commit ke branch main.
3. Tunggu GitHub Pages selesai deploy.
